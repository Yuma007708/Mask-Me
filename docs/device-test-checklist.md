# 実機テスト観点リスト

Simulator では**原理的に出ない**不具合を実機で潰すためのチェックリスト。
机上・Simulator で埋まる項目はここに載せない（それは既存のテストの仕事）。

優先度は「落ちたときの被害 × 実機でしか出ない度合い」で付けている。
**P0 を全部通すまでリリース判断をしない。**

計測は Xcode のコンソールで以下のタグを拾う:
`[MMSCAN]`（プリスキャン）/ `[MMEXPORT]`（書き出し）/ `[MMCAM]`（撮影）/
`[MMLIVE]`（ライブ検出）/ `[MMLOAD]`（読み込み）

記録する端末情報: 機種 / iOS バージョン / 残バッテリー / 開始時の端末温度（触った体感で可）

## P0 — 実機でしか出ない、落ちたら使い物にならない

### 1. ハードウェアデコーダの奪い合い（この案件で全滅の前科あり）

同時にデコードを要求する経路が 3 つある: 再生（AVPlayer）/ プリスキャン /
**自動追跡（今回追加）**、加えてタイムラインのサムネ生成。実機のデコーダは有限で、
奪い合うと数秒後から `copyCGImage` が nil を返し続け、**エラーも出さずに**
検出やモザイクが消える。

| # | 手順 | 合格基準 |
|---|---|---|
| 1-1 | 3 分以上の動画を読み込み、プリスキャン中に再生を開始 → 30 秒再生 → 停止 | `[MMSCAN]` に `copyCGImage=NIL` が連続で出ない。停止後にスキャンが再開して `DONE` まで到達する |
| 1-2 | 矩形を置いて自動追跡が始まった直後に再生を開始 | 追跡バッジ（%）が止まり、再生を止めると再開する。バッジが 100% まで到達する |
| 1-3 | 追跡中にタイムラインを高速スクラブし続ける（サムネ生成が走る） | 追跡が完走する／プレビューが黒くならない |
| 1-4 | 追跡中に**書き出し**を押す | 再生が止まり、追跡完了後に書き出しが始まる。**押しても何も起きない状態にならない**（デッドロック回帰の検査） |

落ちたときの見どころ: `[MMSCAN] copyCGImage=NIL domain=... code=...` の連続。
`code=-11800`（unknown）や `-11819` はデコーダ枯渇の典型。

### 2. メモリ圧によるスキャン全滅

full-res フレーム＋検出中間バッファが溜まると、実機のデコーダがメモリ圧で失敗し、
**キャッシュが冒頭数秒しか埋まらないまま完走したように見える**。

| # | 手順 | 合格基準 |
|---|---|---|
| 2-1 | 4K・3 分以上の動画で最後まで再生 | 動画の**終盤**でもモザイクが顔に乗る（冒頭だけ乗って後半で消える＝この症状） |
| 2-2 | 同じ動画で Xcode の Memory ゲージを見ながらスキャン完走 | ピークが端末上限に張り付かない。`[MMSCAN] DONE samples=` の件数が尺 × 15 とおおむね一致 |
| 2-3 | 4K 動画に矩形を 3 個置いて全部追跡させる | 3 本とも軌跡ができる（追跡は 1 パスで全マスクを追うので、ここが 3 倍遅くなっていたら共有が壊れている） |

### 3. 撮影の座標系（フロントカメラの鏡像・向き）

規約: フレームは常にポートレート回転・非ミラーに正規化し、**鏡像は表示レイヤーだけ**。
ここが崩れると「画面では顔に乗っているのに、保存した動画では左右反対の位置」になる。

| # | 手順 | 合格基準 |
|---|---|---|
| 3-1 | フロントカメラで顔を画面の**左寄り**に置いて撮影 → 保存物を写真アプリで確認 | プレビューと保存物でモザイクが同じ側に乗る |
| 3-2 | 端末を横向きにして撮影 | 顔検出が落ちない・モザイクが 90° ずれない |
| 3-3 | イン／アウトカメラを切り替えながら撮影 | 切り替え直後に前のカメラの顔位置が残らない |

### 4. 原本が残らないこと（プライバシー設計の根幹）

規約: 撮影は**モザイク焼き込み済みメディアだけを保存**する。

| # | 手順 | 合格基準 |
|---|---|---|
| 4-1 | 撮影 → 保存 → 写真アプリを確認 | モザイク済みが 1 本だけ。原本が並んでいない |
| 4-2 | 撮影中にアプリを強制終了 | 中断された録画の原本が写真アプリにも tmp にも残らない |
| 4-3 | 撮影画面から戻る／電話着信で中断 | 同上 |

### 5. 検出率の退行（誤モザイクより重い）

| # | 手順 | 合格基準 |
|---|---|---|
| 5-1 | 実顔 5 パターン（正面 / 横顔 / うつむき / 逆光 / 小さい顔）を撮影・読み込み | 顔一覧に出る。検出率バッジが極端に低くない |
| 5-2 | 複数人（3 人以上）が入れ替わる動画 | 選んだ人にだけモザイクが乗り続ける。フレームアウト→再入で外れない |
| 5-3 | マスク着用・眼鏡・帽子 | 検出できる（できない場合は仕様判断として記録する。`probe_crowd_03` の保留事項） |

## P1 — 実用に耐えるかを決める

### 6. 処理時間と発熱

**数字を残すこと。** 体感で「遅い」と書いても次回と比較できない。

| # | 条件 | 記録する値 | 目安 |
|---|---|---|---|
| 6-1 | 1080p 60 秒・顔のみ・書き出し | `[MMEXPORT] frames= videoSec= wall=` | 実時間の 1〜2 倍以内 |
| 6-2 | 4K 60 秒・顔のみ・書き出し | 同上 + 端末温度 | 熱で throttle しないこと |
| 6-3 | 1080p 60 秒に矩形 1 個 → 自動追跡の所要時間 | 追跡バッジ 0→100% の実時間 | 素材尺の 1 倍以内（Simulator 実測は約 0.3 倍） |
| 6-4 | 4K・2 クリップ・クロスフェード・書き出し | wall + 温度 | 完走する（2 系統デコードの前科あり） |
| 6-5 | 10x 速度のクリップを含む書き出し | wall + 出力の尺 | フレーム洪水で落ちない |

打ち切り判断: 端末が「高温のため…」の警告を出したら**そこで記録して中止**。
何分でそうなったかが結果。

### 7. 自動追跡の実素材での追跡率（今回の新機能）

合成映像では 98.9% だが、実素材は別物。**低テクスチャ・遮蔽・被写体ブレ**で切れる。

| # | 素材 | 見るところ |
|---|---|---|
| 7-1 | 手に持って動かす物（スマホ・カバンなど） | 最後まで貼り付くか。剥がれた時刻を記録 |
| 7-2 | 無地の物（白い紙・単色の服） | 追跡が凍結するはず。**凍結後に背景と一緒に流れていないこと**（流れていたら凍結ロジックが効いていない） |
| 7-3 | 途中で人の後ろに隠れて出てくる物 | 隠れた位置で止まる。キーフレームを 1 個足すと再開する |
| 7-4 | 画面外へ出て戻ってくる物 | 位置が飛ばない |
| 7-5 | 手ブレの強い手持ち撮影 | 追跡が切れない（切れたら `maxExtrapolationFrames` の調整候補） |

各ケースで **プレビューと書き出し結果が一致するか**を必ず見る（設計の中心的な主張）。

### 8. 編集操作の実機通し（S1〜S11 の統合）

| # | 手順 | 合格基準 |
|---|---|---|
| 8-1 | 動画 2 本 + 写真 1 枚 → 結合・並べ替え・分割 | 順序どおり再生される |
| 8-2 | 0.5x / 2x / 10x の速度変更 | 音のピッチが保たれる・尺が正しい |
| 8-3 | クロスフェード + ワイプ | 継ぎ目でモザイクが消えない・両側の顔に乗る |
| 8-4 | 適用区間を指定 | 区間外は素の映像。境界フレームでプレビューと書き出しが一致 |
| 8-5 | 矩形を置く → クリップを分割 | 矩形が両側に残り、位置がずれない |
| 8-6 | undo / redo を 20 回連打 | 状態が壊れない・落ちない |

### 9. 下書きの復元

| # | 手順 | 合格基準 |
|---|---|---|
| 9-1 | 編集 → 下書き保存 → **アプリを強制終了** → 再起動 → 復元 | 顔選択・矩形・キーフレーム・タイムラインが戻る |
| 9-2 | 復元直後に自動追跡が走るか | 追跡バッジが出て完走する（軌跡は保存していないので再計算される設計） |
| 9-3 | 復元直後に**すぐ書き出す** | 追跡完了を待ってから始まる。プレビューと結果が一致 |
| 9-4 | 素材を写真アプリから削除してから復元 | エラーメッセージが出る（無言で壊れない） |

## P2 — リリース前に一度は通す

| # | 観点 | 手順 |
|---|---|---|
| 10-1 | 空き容量不足 | 端末の空きを 1GB 未満にして 4K 書き出し → 開始前に弾かれる |
| 10-2 | 写真アクセス権限 | 権限を「なし」「選択した写真のみ」に変えて保存・読み込み |
| 10-3 | 低電力モード | ON で撮影・書き出しが完走する |
| 10-4 | 通話・通知による中断 | 撮影中・書き出し中に着信 → 復帰できる |
| 10-5 | バックグラウンド遷移 | 書き出し中にホームへ → 戻ると継続または明示的に失敗 |
| 10-6 | 長尺 | 10 分の動画で通し（尺に比例した時間で終わる） |
| 10-7 | 縦動画・横動画の混在 | レターボックスでモザイクが黒帯にずれない |
| 10-8 | 古い端末 | 対応下限（iOS 16 の実機）で起動〜書き出し |
